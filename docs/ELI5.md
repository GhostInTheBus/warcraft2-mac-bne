# ELI5

Warcraft II is an old game made for old computers. Your new Mac cannot run it directly.

Some kind people rebuilt the game's engine so it runs on modern machines. They did not copy the game itself, because that belongs to Blizzard. The engine is like an empty toy box. The art, music and levels have to come from your own game disc.

So we do three things:

1. Take the stuff off your disc.
2. Let the engine's helper tool repack it into the shape the engine likes.
3. Fix two small gaps in the Mac version: it was missing one part it needs, and one folder was in the wrong place.

After that, you double click the app and the game starts.
