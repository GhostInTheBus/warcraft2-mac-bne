# Contributing

Issues and pull requests are welcome.

* Open an issue first for anything bigger than a typo, so we can agree on the approach.
* Keep scripts plain zsh, no extra dependencies beyond Homebrew packages.
* Never attach or commit game files, disc images or extracted game data. Describe the problem instead and paste the script output.
* Bugs in the game itself belong upstream at [Wargus](https://github.com/Wargus/wargus/issues). Bugs in these scripts or the setup steps belong here.
